- **One provider kind `native`** replaces `better_auth`: any client that speaks the native protocol is a verified users / activation / conversion source. `config.source` names the adapter (`better-auth` · `prisma` · `drizzle` · `convex` · `authjs` · `custom`); `better_auth` stays accepted as an input alias (API / MCP / detection) and existing rows are rewritten by `migrations:nativeV1` (integrations, snapshots, stage snapshots, sync runs). Trust base 40, "Verified via Prisma (UserTrack SDK)" provenance, per-source default base path (`/api/auth` vs `/api/usertrack`), per-source 404 wording and minimum client version.
- **`@usertrack/protocol` 0.1.0** (`packages/protocol`): the v1 signing scheme extracted (WebCrypto only, zero deps), wire types with the additive `users` / `activation` / `conversion` / `identities` blocks, `source` + `clientVersion` (`pluginVersion` / `provider` kept as deprecated aliases), five lifecycle event types, `EVENTS_PATH` `/api/integrations/native/events` + `LEGACY_EVENTS_PATH`. Fixtures moved here (two new cases); `convex/lib/nativeProtocol.ts` is the self-contained server twin, pinned by the fixtures and a randomised cross-implementation test.
- **`@usertrack/node` 0.1.0** (`packages/node`): `createUserTrackHandler({ projectId, secret, users, activation?, conversion?, identities?, source?, debug? })` → WHATWG fetch handler (Next.js route export, Hono, Remix, Bun, Cloudflare) + `toNodeHandler()` (Express / `node:http`); count sources are `{ count({ createdAtGte?, createdAtLt? }) }` with `exact: false` and `timeFilter: false` escape hatches; `createTracker().track(type, { id, at? })` fire-and-forget push.
